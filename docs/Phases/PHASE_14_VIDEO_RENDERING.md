# Phase 14: Video Rendering Engine

## Overview
This phase translates the mathematical timestamps generated by Gemma AI into actual, physical video files. When a user approves a candidate clip from the Clip Lab, the renderer physically slices the cached high-resolution source video and exports a perfectly timed `.mp4`.

## Key Features
- **Vertical 9:16 Cropping:** The renderer has been upgraded to automatically center-crop the 16:9 source video into a perfect 9:16 vertical ratio (TikTok/Shorts format) using the FFmpeg `-vf "crop=ih*(9/16):ih"` filter.
- **Fast Re-Encoding:** Since cropping requires re-encoding, it utilizes the `libx264` codec with the `veryfast` preset and `crf 23` to preserve high quality while ensuring rendering happens in seconds, not minutes.
- **Asynchronous Execution:** Just like downloads and transcription, rendering occurs completely in the background, preventing the UI from locking up.
- **Automated Output Management:** The sliced clips are automatically saved to the local `outputs/` directory using sanitized names (stripping emojis and invalid characters) so they are ready for upload.

## Components Built
- `src.services.media.renderer.VideoRenderer`: Encapsulates the FFmpeg subprocess commands specifically tuned for rapid video trimming.
- `src.ui.views.clip_lab.ClipLabView`: Wired the UI so clicking the green `[ Approve to Queue ]` button instantly triggers the renderer and updates the status label with the absolute path of the generated `.mp4`.

## Transition
The core viral-clipping loop is completely functional! The next stages (e.g. 9:16 vertical reframing, overlaying animated subtitles) will intercept this rendering step to add visual flair.
